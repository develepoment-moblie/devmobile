# Nova Paris

Flutter app for local user management, room management and housekeeping. The
normal app stores data on the device with SQLite.

## Run

```powershell
flutter pub get
flutter run
```

## Documentation

Project guides and design notes are in [`docs/`](docs/README.md). Start with the
[SQLite setup guide](docs/SQLITE.md). The standalone housekeeping demo backend
has its own [README](backend/README.md).
